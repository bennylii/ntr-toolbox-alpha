📝 Tampermonkey 配置方法

要将本地脚本文件添加到 Tampermonkey，请按以下步骤操作：


// 1. 在 Tampermonkey 中创建新脚本
// 2. 复制 ntr-toolbox-alpha.user.js 的全部内容
// 3. 修改 @match 规则以匹配本地文件：

// ==UserScript==
// @name         NTR Toolbox Alpha (Local Debug)
// @namespace    http://tampermonkey.net/
// @version      v0.7.1-debug
// @match        file:///C:/cache/models/debug-env/pages/*.html
// @match        https://books.fishhawk.top/*
// @match        https://books1.fishhawk.top/*
// @match        https://n.novelia.cc/*
// @grant        GM_openInTab
// ==/UserScript==

(function() {
    'use strict';
    // ... 脚本内容 ...
})();
⚠️ 注意：由于浏览器的安全限制，直接打开本地 HTML 文件时可能无法加载外部 JS 文件。 建议使用以下方法之一：

1. 使用 Live Server 或类似工具启动本地服务器
2. 将脚本内容直接嵌入到测试页面中
3. 在 Chrome 启动参数中添加 --allow-file-access-from-files

🚀 快速启动本地服务器

# 方法1: 使用 Python
cd C:/cache/models/debug-env
python -m http.server 8080

# 方法2: 使用 Node.js (需要安装 http-server)
npx http-server -p 8080

# 然后访问: http://localhost:8080/pages/novel.html

🔍 调试技巧

  • 打开浏览器的开发者工具 (F12)
  • 查看 Console 标签页可以查看脚本的日志输出
  • 使用页面上的调试按钮执行各种操作
  • 在 Storage 标签页可以查看 localStorage 的变化
  • 使用 Network 标签页可以查看 API 请求
