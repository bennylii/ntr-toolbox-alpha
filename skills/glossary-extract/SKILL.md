# 术语提取与整理

本技能面向 NTR ToolBox 的「AI提取术语表」链路（含术语队列）。目标是**高召回地发现候选、高精度地核实定名**，并把每条结论落到可验证的证据上。

先按任务读取资源：

|任务类型|资源文件|
|---|---|
|判断某个词该不该收、译名边界怎么定|`references/rule.md`|
|跑一轮提取、整理已有术语表、发现遗漏|`references/extract.md`|

## 基本立场

- 术语表的价值在**落地**，不在数量：一条永远用不上的条目不如不收；收集后必须能通过「验收回扫」检查。
- 判定顺序：用户明确指定 → 工程内已有证据 → 已核验的同类对象 → 一般语言知识。工程反例优先于一般经验。
- 频率高不构成收录理由：普通词出现一千次也还是普通词。
- 结果是给人看的：改动要有快照可回滚（工具链已有），批量写入前先进「待确认」。

## 一键合规生成（对齐站点《术语表使用指南》）

想要无人值守地生成一份合规术语表，这样配置：

1. 「AI提取术语表」：任务方式 = **加入队列**；模式 = 写入；**种子补漏 + 种子轮数**（默认 3）、**证据核实**（默认开）保持打开；
2. 「术语队列」：**自动续跑** 打开；**自动确认纯新增** 打开；
3. 队列跑完时只有同时满足以下条件才会免审写入：纯新增（无冲突/无覆盖）、无形态可疑（过长/像短语/带敬称/含标点）、无疑似改原文、无「核实建议剔除」条目——任一不合格都会自动留在「待确认」等你人工过目；
4. 写入时会按指南写出简单备注（如 `阿尔蒂 #女性`），并保留站点上已有的备注。

增强管线两件事（相对早期版本的增量）：

- **多轮种子账本**：主轮收敛后逐轮派生"带具体调查目标"的种子（敬称裸名/称谓写法/平假名写法/未收录片假名信号），新发现物派生新种子，直到无新种子或轮数封顶；账本随任务持久化，中断续跑不重复调查；
- **证据核实**：把每条候选的命中行与上下文打包给模型做正向判定（收录资格/类型）；判定为剔除的条目标「核实建议剔除」保留在任务里供人工复核，但**不参与自动写入**。

度量：`node tools/ab-boost.mjs --text <book.txt> --endpoint <url> [--verify drop-first]` 在同一文本上对比基线/增强（条目数、核实剔除数、请求数、耗时），报告写 `tools/.ab-report.json`。

指南硬性纪律（工具会标记，但最终由你把关）：

- **绝对禁止**改原文/插控制符（`rem0 => …` 类）：导入与填充路径会标记「疑似改原文」；
- 禁止把不存在于这本书的术语批量导入：「导入术语表(KWG)」的「检查正文」会标出「书中未见」；
- 备注只写简单标签（≤8 字、不含句读），禁止写作文。
