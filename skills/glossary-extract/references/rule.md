# 收录判据与字段纪律

## 什么该收

术语表保存**普通翻译难以稳定推出的固定信息**，具体包括：

- 人名、别名、姓氏、家族、地名、组织、作品特有的物品、技能、生物、概念——只要身份能合理建立、且需要整部作品内保持一致；
- 需要消歧的同名对象（同名不同人、同名不同地）；
- 影响译法的人称/称谓/性别/阵营事实（写进条目的 info 字段）。

## 什么不该收

- 普通职业、称谓、描述性表达——除非它承担必要的身份、消歧或特殊译法功能；
- 高频的普通名词（出现次数、重复度、与专名的字符相似度都不能单独证明资格）；
- 整句、短语、含句读的混合串（「AI提取术语表」的后处理会自动丢弃并计数，别和它对抗）。

## 实体、名称、条目是三个概念

- **实体** = 名称指向的对象；**名称** = 它的各种写法；**条目** = 术语表里的一行。
- 同一实体可以有多个名称（本名/别名/昵称/敬称），能安全合并的合并，必要的区别保留；条目数量不等于实体数量。
- 同一名称可能指向不同实体，必须依据语境消歧；无法区分时拆成条件性条目或保留原始写法。
- 人物与其创立的组织是两个实体，不要合并。

## 字段纪律

|字段|要求|
|---|---|
|`src`|原文中的精确连续字面量，取**最短且自然稳定的边界**；运行时按字面匹配，边界错会吞普通词|
|`dst`|非空固定译文，与身份、含义、适用条件一致|
|`info`|只写影响译法且**能从局部上下文判断**的事实（如「男性角色」「女仆」「敌对阵营」）；判断不了的不要写|
|大小写|只有在真实碰撞（不同对象仅靠大小写区分）时才开大小写敏感|

## 备注与值格式（站点约定）

- 站点把备注存在值里：`译名 #备注`（如 `アルティ #女性`），翻译时按第一个 `#` 截断；
- 备注只写**简单标签**（≤8 字、不含句读）——指南禁止在备注里写作文，Sakura 也只认简单备注；
- 我们写入时会按提取类型自动生成简短备注（男性人名→`#男性`、女性人名→`#女性`、地名/组织/家族/物品/生物同理）；译名未变时保留站点上已有的备注；
- 读入时会剥离备注再做匹配/比对（否则带备注术语会被误判「未落地」）。

## 存在性与原文污染纪律（指南硬性要求）

- **绝对禁止**通过修改原文/插入控制符来操控翻译（典型反例 `rem0 => 真白萌有翻译`）。工具会标记「疑似改原文」（含控制符、或纯拉丁数字且无假名汉字）；
- 禁止把**不存在于这本书**的术语批量导入（尤其通用术语表）；「导入术语表(KWG)」的「检查正文」会标出「书中未见」；
- 以上标记**只提示不自动删**——是否剔除由人决定（与"漏删的代价远小于误删"一致）。

## 词根与分支

同一实体的多个词形（如一族人名、同一组织的不同写法）：

1. 列出所有已确认词形与固定译名；
2. 枚举公共连续片段作为**词根候选**，从短到长逐项确认：成员身份一致、固定译文可组合、剩余文本能按语境正常组合、词根不会吞掉必要的身份区别；
3. 词根 + 精确分支共同覆盖；没有安全合并方案就保留精确条目；
4. **任何合并/删除/调整后，重新核对每条原条目是否仍被覆盖**——数量相同不证明覆盖相同。

工具侧的「词根整理」模块给出自动化建议版：只提议"全体成员的共同前缀/后缀"（中段偶合片段不算），
译文词根取成员译文的公共部分，并核对**新增命中**（词根命中而所有成员都没命中的行，附样例）。
新增命中为 0 = 合并安全；> 0 时必须先看样例——那些行可能正是要覆盖的新对象，也可能是词根过宽吞掉了普通词。

## 判断不了的怎么办

- 证据不足的对象不要硬写结论：保留原样、标注待查，或进人工复核；
- 一条判据的优先级：用户明确指定 > 工程语境 > 已核验同类 > 一般知识。
