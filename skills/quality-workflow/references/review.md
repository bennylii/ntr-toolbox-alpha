# 七码审校参考（判据 / 误报排除 / 处置）

> 本文件是 `quality-workflow` 的路由明细：SKILL.md 给入口与循环，这里给每个码的判据、误报排除与处置口径。工具名与字段以 daemon 工具为准（`quality_report` / `list_warnings` / `read_translations` / `read_book` / `workspace_run`）。

通用纪律：**先取证再下结论**——每个结论都要能指回具体的 `chapterId + lineNo + evidence`；结论三态为「修正（产提案）/ 保留（写明依据）/ 未决（写明缺失事实与继续条件）」。

## LINE_COUNT_MISMATCH（缺译/行数不符）

- **判据**：原文行有内容而译文为空（`译文缺失`），或章节整体缺译（报告里的 `translationMissing` 计数）；逐对判定，行数不齐即命中。
- **误报排除**：原文行本身是空行/纯控制符时译文为空属正常（空行保留原文，不报）；报告里 `translationMissing ×N` 是整章级缺失标记，不是单行——先 `book_status` 对照已译章数，确认是"没翻"还是"翻了但某行空"。
- **处置**：整章没翻 → 建议 `run_translate`（expire 档）补翻（写操作，走审批）；个别行空 → 与 `FOREIGN_CHAR_RESIDUE` 同路径（修句提案）。

## FOREIGN_CHAR_RESIDUE（译文里残留假名）

- **判据**：译文按字素分类后含非目标脚本片段（假名/谚文/西里尔等）；相邻残留合并成片段进 `evidence.fragments`。拉丁短串豁免（单字素或 `^[A-Z]{2,4}$`）。
- **误报排除**：合法保留的英文缩写/品牌名（≤4 位全大写）不报；引号内原文引用、拟声词残留要看上下文——先 `read_translations` 取该行上下文再定性。
- **处置**：个别行残留 → 修句**提案**（给出建议译文与依据）；整章大面积残留（模型直抄原文）→ `run_check` 复核后建议整章 `run_translate`（expire 档）。

## SIMILARITY（译文≈原文）

- **判据**：trim 后双向包含，或字符集 Jaccard > 0.8；日→中方向**需同时有残留证据**才报（防汉字-heavy 的合法译文误报）。
- **误报排除**：短行（专有名词、拟声词）与原文同形有时是合理译法；汉字段落译文与原文用字相近但语义正确时不报——没有残留证据时本码不会命中，命中即有残留，仍要人看一眼是"抄原文"还是"该保留"。
- **处置**：同 `FOREIGN_CHAR_RESIDUE`；与残留码同时出现时按同一问题处理，汇报时合并计数。

## GLOSSARY（术语未落地）

- **判据**：术语表的 `src` 在原文出现，但译文里找不到对应译名（复用验收回扫语义）。
- **误报排除**：术语是常见汉字词时可能在他处误命中；一章未译时整章计为未落地；译名过短/纯标点属"不可检"，不进分母。看 `evidence`（原文样例与命中计数）再下结论。
- **处置**：转 `glossary-workflow`——先 `list_proposals` 看是否刚写过该术语，再 `read_translations` 看该术语出现处是"翻译没跟上"还是"条目本身该改"；改译文走修句提案，改表走术语写入（审批）。落地率口径引用 `acceptance-scan`：已落地 ÷（已落地 + 未落地）。

## PUNCTUATION_MISMATCH（标点结构不一致）

- **判据**：两侧标点组序列逐位比对（引号变体合并、开闭分明、顺序敏感）；结构不同即命中。
- **误报排除**：中日标点习惯差异（如中文用「。」替代「．」、引号样式不同）可能合法；单行标点缺失无结构影响时不报。**同章少量出现属噪声，优先级低**。
- **处置**：默认保留并写明依据；同一章大量出现（模型输出风格漂移）才建议整章重跑。

## TEXT_PRESERVE（保留段/控制码缺失）

- **判据**：按处理链同款规则从原文/译文两侧提取受保护片段（标签、控制码、占位符），逐位比对，数量或内容不一致即命中，`evidence` 给两侧片段。
- **误报排除**：控制符在预处理阶段被投影、后处理阶段还原——先确认该章翻译时用的处理链预设（`text-preserve` 技能）；两侧片段数一致但顺序不同也要看是否等价。
- **处置**：个别段丢占位符 → 修句提案；整章系统性丢失 → 检查处理链规则（`text-preserve` 技能）后再建议重跑该章，否则重跑仍会丢。

## RETRY_THRESHOLD（该章翻译时重试 ≥2 次）

- **判据**：章节翻译记录 `retries >= 2`（来自章节元数据，不是译文内容问题）。
- **误报排除**：上游限流/链路抖动导致的重试与译文质量无关；重试后最终放行的译文可能完全正确。
- **处置**：只读人工判断——`read_translations` 抽样看该章译文，没问题就保留结论并写明"上游不稳所致"；**不改任何数据**。
