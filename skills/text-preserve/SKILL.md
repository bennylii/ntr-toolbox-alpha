# 文本保护（网页小说场景）

目标：**翻译时不动标记，标记不干扰术语判断**。本技能目前是规划性文档，供「验收回扫」的上下文判断与后续「修句」链路引用；工具侧已具备的能力见括号标注。

## 常见标记形态

|形态|例子|处理|
|---|---|---|
|ruby 显式写法|`|漢字《かんじ》`、`<ruby>漢字<rb>漢字</rb><rt>かんじ</rt></ruby>`|提取/匹配前清洗为汉字再比对（`cleanRuby` 已覆盖常见格式）|
|隐式注音|`漢字（かんじ）`、`[r_かんじ][ch_漢字]`|同上|
|分隔/装饰|`＊`、`※`、`──`、`□■`|不参与术语匹配；整行纯装饰行跳过|
|控制串|`\n[xx]`、`%{...}`、HTML 实体|翻译时原样保留；术语匹配跳过含控制串的片段|

## 原则

1. **提取**：先清洗 ruby/装饰再统计与匹配——否则同一个名字会因注音写法不同被算成两个词（这是「原文未见」误报的常见来源）；
2. **翻译**：标记不翻译、不删除；含标记的行分段处理，只翻自然语言部分；
3. **验收**：译文的匹配同样先做归一化；不要把标记本身当作命中证据；
4. **新标记要沉淀**：遇到未覆盖的写法，补进清洗规则并加单测（`tools/engine-test.mjs`），不要局部硬编码。
